# Gate 0 Kill Criteria 1.0

Hard project budget from Gate -1 through Gate 1 is fourteen calendar months or six person-years,
whichever comes first. Budget exhaustion triggers stop/pivot/new-funding review without technical
attribution.

Gate 2 requires:

- H1a and H2a pass;
- H3a passes or is unverifiable solely because of the single-module boundary;
- no failed hypothesis;
- experiment validity checks are green;
- a pilot team commits to continue;
- a separately approved Gate 2 budget.

The experiment lifecycle permits one amendment/retest only:

```text
Planned → Running → InitialResult
Inconclusive/Invalid → AmendmentReview → Retest → Pass/Fail/Unverifiable
```

Terminal budget stop, failure, and unverifiable states cannot silently return to running.
